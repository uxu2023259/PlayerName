# NameTagSync 插件图标设计方案

## 推荐图标方向
方形图标，深色 Minecraft 风格背景，中间放置一个玩家头像剪影，头像上方悬浮彩色名牌文字“VIP Steve”，名牌左右带轻微像素光效，整体突出“头顶名称同步”和“权限组称号”。

## AI 绘图提示词
Create a square Minecraft server plugin icon. Dark clean pixel-art inspired background, central blocky player avatar silhouette, a glowing floating name tag above the head with Chinese-friendly visual space and the text "VIP Steve", gold and cyan accents, clean high-contrast composition, modern MineBBS resource icon style, no watermark, no extra text except "VIP Steve", sharp edges, app icon quality.

## 配色建议
- 背景：深蓝黑 `#101827`
- 主强调：金色 `#facc15`
- 辅助强调：青色 `#22d3ee`
- 名牌底色：半透明深灰 `#1f2937`

## 使用建议
MineBBS 资源图标建议使用 1:1 方图。若平台压缩较明显，请优先选择文字少、主体大的图标版本。
